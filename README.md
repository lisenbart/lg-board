# LG Board — SUPERPLAY MGX

Sandbox demo of the Lisenbart studio desk. Superplay stays on Monday `External Weekly`. Designers work here and are never added to Monday.

This pack is **test data**, not the live October board.

Open `index.html` (or the GitHub Pages URL). Use **I am** to try Manager, Team lead, and Designer.

Until Monday is connected: paste briefs and Drive links in a project, **Send to client** copies `check it please` + the result link, **Copy Telegram** is for the studio chat, **Excel CSV** is the month hours file.

The **Excel** tab is the load sheet from `SP_MGX_check.xlsx`: project rows, people columns, hours in the cell.
